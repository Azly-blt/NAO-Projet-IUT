# Test 2 — RTSP / RTP

## État du test

Le test n'a pas été poursuivi sur les machines de l'IUT.

Les outils nécessaires envisagés pour le prototype, notamment FFmpeg et VLC, ne sont pas installés sur les postes testés.

Les utilisateurs ne disposent pas des droits administrateur nécessaires pour installer librement de nouveaux logiciels.

RTSP/RTP reste une solution intéressante pour la transmission vidéo à faible latence, mais son intégration n'a pas été retenue comme priorité dans l'environnement actuel.

La prochaine solution étudiée est WebRTC, car elle peut être intégrée directement avec Python et un navigateur web.
